# Maps

Every map is generated by the game's code from fixed seeds. A file here
replaces parts of one world's map, as the author placed them in the map
editor (`build/dev.html?screen=map-editor&world=3`; see the README).

One file per world and layout: `<world>-<layout>.json`.
- **world** is the world's name in lower case, its spaces as hyphens: `haven`,
  `verdant`, `dustfall`, `ion-reach`, `obsidian`, `cryosphere`, `nova-forge`,
  `eclipse`.
- **layout** is `campaign` (the campaign and the Races mode), `free` (arcade
  Free) or `lane` (arcade Scroll and Base, which fly the same lane; Base has no
  world tricks, so it leaves out the pylons, spires, cliffs, storms and hole).

`bin/build` packs every such file into the game, and fails naming the file if
one is not a map: an unknown key, a place without its numbers or out of the
map, a kind the world does not have. `bin/map-check` checks the map each file
makes against [docs/placement.md](../../docs/placement.md). With no file the
game's maps are the generated ones.

A file holds only what it changes; each kind is a whole list, and a kind left
out is generated as before, round what the file moves: the gates, beacons,
portals, storms, pylons and spires are placed round an edited station, and the
drifting debris round edited fields. Places are in metres from the map's top
left corner; `size` is the world's size they were made for (a world of another
size scales them).

    {
        "size": {"w": 12000, "h": 10000},
        "station": {"x": 6000, "y": 5000},
        "fields": [
            {"x": 5400, "y": 5440, "rocks": [{"x": 5380, "y": 5500, "r": 31}, {"x": 5460, "y": 5390, "r": 40}]}
        ],
        "caches": [{"x": 6900, "y": 4700}]
    }

| Key | Each | Where the game has it |
|---|---|---|
| `size` | `{w, h}`, required | |
| `station` | `{x, y}`; it moves only | every map |
| `fields` | `{x, y, rocks: [{x, y, r}]}`, a rock field (260 m) and its rocks; a field with rocks centres on them | every map |
| `caches` | `{x, y}`: salvage and a supply (a Base run's: the supply only) | every map |
| `holes` | `{x, y, radius, core}`, a black hole: it pulls within max(2.8 × radius, radius + 1700) m | the campaign, arcade Eclipse |
| `storms` | `{x, y, r}`; flares in Nova Forge | Ion Reach, Nova Forge |
| `pylons` | `{x, y}`, an arc pylon | Ion Reach |
| `charge_fields` | `{x, y}`; one within a pylon's 230 m is the one beside it; it goes with `pylons`: a file with either has none of the other it leaves out | Ion Reach |
| `spires` | `{x, y}`, a magnetic spire | Obsidian |
| `cliffs` | `{x, y, r, fall, rubble: [{x, y, r}]}`, `fall` the way it falls (radians) | arcade Dustfall |

A save keeps a world's rocks and caches as you left them, with the map file
they were on: a save made on another map (or before the file) starts that
world's rocks and caches afresh from the file.
